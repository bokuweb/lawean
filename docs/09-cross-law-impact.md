# 09. 他法令への波及 — 法令 A の改正は A の中では正しいが、A を参照する法令 B に矛盾を生む

状態: §6 の 1〜5 を実装（`crates/lawean-space`）。**テスト計画 1〜5 がすべて意図どおりに報告される**（§5）。
Lean（§4）は未着手。方針は [ADR-0010](adr/0010-amendment-first.md) / [ADR-0011](adr/0011-lean-as-reference-for-consolidation.md)。

## 1. ユースケース

改正法を書く（または審査する）人が知りたいのは次の 3 つ:

1. **改正法自体が正しいか** — 発射台に溶け込むか、A の中の参照が壊れないか（[08](08-amendment.md) で実装済み）
2. **A を参照する法令 B に影響があるか** — B の参照が指す先がずれる・消える（他法令へのハネ）
3. **影響の結果、ある施行時点で B に矛盾があるか** — 参照が形式的には解決しても、指す先の**意味**が変わって B の前提が崩れる。あるいは A と B の**施行時期**がずれて、その間だけ B が存在しない規定や旧規定を指す

1 は A だけで閉じる。2 は参照グラフ。3 は意味層と時間の話で、ここが本題。

## 2. 実データ（すべて e-Gov から取得済み、`fixtures/laws/`）

**A = 借地借家法**（403AC0000000090）。令和3年法律第37号 第35条で第38条に 2 項が挿入され、旧第4〜7項が第6〜9項に繰り下がった（2022-05-18 施行）。

**B = 高齢者の居住の安定確保に関する法律**（413AC0000000026）。借地借家法の Rule を**上書き・排除**している:

| B の条文 | A への参照 | Semantic IR での関係 |
|---|---|---|
| 第52条第1項「…公正証書による等書面によって契約をするときに限り、**借地借家法第三十条の規定にかかわらず**、…賃借人が死亡した時に終了する旨を定めることができる」 | 第30条（第3章第1節の強行規定） | B の Rule が A の R30 を `overrides`（外部 Rule への上書き） |
| 第52条第1項ただし書「定期建物賃貸借（**借地借家法第三十八条第一項**の規定による建物賃貸借をいい…）」 | 第38条第1項 | 定義の借用 |
| 第58条「**借地借家法第二十八条**の規定は、前項の解約の申入れについては、**適用しない**」 | 第28条 | B の Rule が A の R28 を `Exception` |
| 第63条「**借地借家法第三十二条**の規定は…適用しない」 | 第32条 | 同上 |
| 「借地借家法**第三章**の規定により賃借人に不利なものとして無効とされる特約については、この限りでない」 | 第3章（Scope） | A の強行規定群への参照 |

**C = 借地借家法施行令**（504CO0000000187、施行 2022-05-18）。「借地借家法**第三十八条第四項**の規定による承諾は…」— 令和3年改正で**新設された項**を指す。施行日は A の改正の施行日と同じ。

B と C が現実に矛盾を起こしているわけではない（令和3年改正は B の参照先である第30条・第38条第1項・第28条・第32条を動かしていない）。
本書で証明したいのは「**もし A の改正がこうだったら B に矛盾が出る**」を、改正案の段階で機械的に言うこと。改正案は自分で書いて fixture にする（検査ツールの用途そのもの）。

## 3. モデル

### 法令空間とリビジョン

```
LawSpace(t) = { law_id ↦ Revision }          時点 t に施行されている各法令のリビジョン
Revision    = Source IR + Semantic IR          Semantic IR は Provenance で Source IR の stable_id に束縛される（[08](08-amendment.md) §6 の 6）
```

改正法の適用は `LawSpace(t) → LawSpace(t')`。1 つの改正法が複数の法令を改正する（整備法）ので、改正単位は `(target_law, ops, enforcement)` の集合。

### 参照グラフ（法令をまたぐ）

`lawean-resolve` は他法令への参照を `Resolution::External { law, num, paragraph }` として返す（法令名 → law_id の対応表が要る）。
これを B → A の辺にする: `(B の文の stable_id, 参照表現, A の stable_id)`。Semantic IR 側では `RefTarget::External { law, path }` と `Override::Rule` / `Effect::Exception` が外部 Rule を指す。

### 波及（impact）

A の改正単位 u に対し、`paragraph_mapping`（[08](08-amendment.md) §4）を条にも拡張した `mapping_u : stable_id(A, before) → Option<stable_id(A, after)>` を取る。B の辺 `(s, text, target)` について:

| 種類 | 条件 | 例 |
|---|---|---|
| **参照切れ** | `mapping_u(target) = None`（削除） | A の第30条を削ったのに B が「第三十条の規定にかかわらず」 |
| **参照ずれ** | `mapping_u(target) ≠ target` で、B の参照が絶対番号 | A の第38条第4項の前に項を挿入したのに C が「第三十八条第四項」のまま → 新第4項（別の内容）を指す |
| **意味変化** | 参照は同じ stable_id に解決するが、その Rule の Semantic IR が変わった | A の第30条の文言を変えて強行規定の範囲が広がった。B の上書きはそのまま |
| **時期不整合** | A の改正の施行日 `t_A` と B（または C）の施行日 `t_B` の間に、B の参照先が存在しない／旧内容である区間がある | C が第38条第4項を指すが、A の改正が `t_C` より後に施行される |

### 矛盾（contradiction）— 施行時点 t の LawSpace(t) について

Semantic IR を A と B をまたいでひとつのモデルにし（B の外部参照を A の RuleId に解決）、07 の意味論で検査する:

| 矛盾 | 定式化 | 検出手段 |
|---|---|---|
| 義務と禁止 | ∃ facts. `applies_R ∧ applies_R'` で R が Obligation(X)、R' が Prohibition(X) | Z3 sat（反例 = その facts） / Lean `decide` |
| 無効の連鎖 | B が「できる」とする特約が、A の強行規定で `void` になる: ∃ facts. `applies_B_power ∧ void(特約)` | 同上 |
| 上書き先の喪失 | B の `Override::Rule(A:R)` の R が A の改正後に存在しない、または効果種別が変わった（Set → Void など） | Resolved IR で静的に |
| 期間の不整合 | B が A の期間を前提に計算した値（「一年以内の期間を定めたものに限る」）が、A の改正後の期間と両立しない | Z3 / `omega` |
| 時期の区間 | `[t_A, t_B)` または `[t_B, t_A)` の区間で参照切れ・参照ずれが起きる | 施行日の比較（決定的） |

「意味的」は上 4 行、「時間的」は最後の行と期間の行。

## 4. 証明したい命題（Lean）

法令空間の上で:

```lean
-- 改正単位 u を A に当てても、A の中の参照はすべて解決する（08 の範囲）
theorem intra_law_ok : refsResolve (applyUnit A u)

-- しかし B の参照のうち少なくとも 1 つは指す先がずれる
theorem cross_law_impact : ∃ e ∈ refs B A, mapping u e.target ≠ some e.target

-- その結果、施行時点 t の法令空間で B の Rule r と A の Rule r' が同時に適用され、効果が矛盾する
theorem contradiction_at (t : Date) (h : t ≥ enforced u) :
  ∃ facts, applies (space t) r facts ∧ applies (space t) r' facts ∧ conflicts r.effect r'.effect
```

`∃ facts` は有限のモデルなら `decide` で、期間を含むなら `omega` の否定形で示す。**反例（facts の具体値）は Z3 に出させ、Lean はその facts を証人として `decide` で確定する**、という分担が自然（Z3 が見つけ、Lean が証明する）。

| # | 改正案（fixture として自作） | 期待 |
|---|---|---|
| 1 | 令和3年改正（実物）+ 施行令（実物、同日施行） | 波及なし。時期不整合なし（`t_A = t_C`） |

| 3 | 借地借家法第38条第3項の次に**もう 1 項を挿入**する改正案（施行令は改正しない） | 参照ずれ: C の「第四項」が新第4項（旧第4項 = 電磁的方法の提供）ではなく別の項を指す。意味変化: C の「承諾」が承諾を要しない Rule を指す |
| 4 | 借地借家法第30条を「この節の規定に反する特約で建物の賃借人に不利なものは、無効とする。**第五十二条の規定による特約についても同様とする**」のように広げる改正案 | 意味的矛盾: B の第52条「第三十条の規定にかかわらず…定めることができる」の特約が A で無効。`applies_B52 ∧ void(特約)` が sat |
| 5 | 借地借家法第28条を削る改正案 | 参照切れ: B の第58条「第二十八条の規定は…適用しない」の対象が無い |

1 が通り、2〜5 で意図した矛盾が**そのまま報告される**ことが受け入れ条件。→ **全部通った**（`crates/lawean-space/tests/cross_law.rs`）:

- 1: 波及なし
- 2: 施行令の「第三十八条第四項」について `Shifted { moved_to: para:6, now_points_to: para:4 }` と `TimingGap { 2022-05-18 → 2023-01-01, before: 「…期間の満了の一年前から六月前までの間…」, after: 「…電磁的方法…」 }`
- 3: 同じく `Shifted`。改正後の第4項は挿入された項（「書面を保存しなければならない」）
- 4: B 第52条の参照先（第30条）に `SemanticChange`。意味層で A:R30b ⇄ B:R52 の**上書きの循環**を検出。Z3: 「書面で契約すれば B52 の特約を定められる」が改正前は証明、改正後は反例（`applies:A:R30b` が真で B52 が偽になる解釈）
- 5: B 第58条の第28条参照が `Dangling`

**参照元の施行日による解釈**: 参照元 L の施行日が改正の施行日より前なら、L の参照は改正前の状態を意図しているとみなして参照ずれ・意味変化・時期の区間を報告する。
同日以降なら改正後の状態を意図しているとみなし、解決できるかだけを見る（施行令が「新設された第4項」を指すのは正常）。
ツールは意図を知り得ないので、時期の区間では改正前後の本文を両方示して人に判断させる。

### 実装して分かったこと

- 施行令は条を持たず本則に項が直に並ぶ（`MainProvision/Paragraph`）。Source IR に `Provision::Paragraph` を足した
- 「第N条を削る」は条そのものを取り除く（番号は残さない）。「第N条　削除」にするのは「次のように改める」の形
- B の「第三十条の規定にかかわらず」は第30条の**全 Rule** に及ぶ。改正で第30条に文を足すと、その文も B に上書きされる。
  足した文が「同項の規定にかかわらず」と B を上書き返すと循環になる — これが「意味的矛盾」の最も機械的な形
