# 07. Verification IR — Semantic IR を SMT に落として性質を検証する

状態: 実装（`crates/lawean-verify`）。z3 で手書き IR（第3・4・9・22条）の性質を証明・反証している。
同じ意味論を Lean の評価器として書き直した（[docs/10](10-lean-semantics.md)、[ADR-0016](adr/0016-lean-as-semantic-backend.md)）。ここの 6 性質は `lean/Lawean/Properties.lean` でも証明済み（Z3 と同じ結論）。証明と改正 × 意味の定理は Lean、反例探索は Z3 のまま併用する。ここの SMT 写像が Lean 版の仕様。

## 目的

「変換できる前提で、IR が検証に使えるか」を先に確かめる（[README](../README.md) の進め方 8）。
自動抽出（層 2）より前に、**IR の形が Z3 に素直に落ちるか**、**証明したい性質が書けるか**、**反例が法的に意味を持つか**を見る。

## 意味論（v0.1）

Semantic IR の各 Rule `R` に Bool `applies_R` を置く。

```
applies_R  ⇔  cond_R  ∧  ¬ applies_X  (X ∈ exceptions_of(R))
```

`exceptions_of` は `overrides` の逆引き（`lawean-resolve::ResolvedModel`）。ただし書き・特則・「かかわらず」はすべてこれで表す。
例外の例外は `applies_X` が自身の例外を含むので自然に連鎖する。

効果は `applies_R` を前件にした含意:

| Effect | SMT |
|---|---|
| `Set(attr, v)` | `applies_R ⇒ a:attr = v` |
| `Deem(fact)` | `applies_R ⇒ p:fact` |
| `Void(target)` | `applies_R ⇒ void:target` |
| `SameAs(R')` / `DeemAndApply{apply: R'}` | `applies_R ⇒ effect(R')`（R' の効果を R の前件で再主張） |
| `Exception(R')` | 追加なし（`overrides` が担う） |
| それ以外 | `applies_R ⇒ eff:R`（Bool の印。性質からは「その効果が生じた」としてだけ参照できる） |

式:

| Expr / Value | SMT |
|---|---|
| `Pred(name, args)` | Bool 定数 `p:name(args)`。**述語は不透明**。同じ名前・引数なら同じ変数 |
| `Cmp(a, op, b)` | Int の比較 |
| `Duration` / `Period` | 月数の Int リテラル（年 × 12）。日・週・時は v0.1 では未対応 |
| `Var(x)` | Int 定数 `v:x`。属性 `a:x` と**同じ名前空間**（「存続期間」を条件で参照すれば R3 が定めた値になる） |
| `RuleValue(R)` | R の `Set` が定める値をインライン展開 |
| `Unknown(...)` | 自由な Bool / Int 定数。評価概念（「不利」「正当の事由」）はこれで自由変数になる |
| `Ref(Rule R)` | `applies_R` |
| `Time(...)` | v0.1 では不透明な Bool |

性質は同じ Expr で書き、`(assert (not P)) (check-sat)` で **unsat なら証明、sat なら反例**（モデルを表示）。
評価概念を含む性質には**補題**（人が書く追加の assert）を添える。補題は IR ではなく検証入力であり、Provenance を持たない。

`tests/proofs.rs`:

| 性質 | 結果 |
|---|---|
| 第3条: 契約期間が何であれ 存続期間 ≥ 30 年 | 証明 |

| 第4条: 更新後の期間 ≥ 10 年 | 証明 |
| 第4条: 最初の更新なら 更新後の期間 ≥ 20 年 | 手書き IR の当初版では**反例**（下記）。修正後は証明 |
| 第22条 × 第9条: 存続期間 ≥ 50 年なら 第9条は適用されない（定期借地権の特約は強行規定に反しない） | 証明 |
| 第9条 + 補題「30 年未満の特約は不利」: 契約期間 < 30 年 ⇒ 特約は無効 | 証明（補題依存） |

### 検証が見つけた IR のバグ

[art-04.md](03-examples/art-04.md) の手書き IR で、ただし書き R4-2 の条件を `当事者が定めた期間 > RuleValue(R4-1)`（= 10 年）と書いていた。
z3 は「最初の更新で 15 年と定めた」を反例に出した: 15 > 10 なので R4-2 が適用され、更新後の期間が 15 年になり 20 年を下回る。
原文の「これより長い期間」の「これ」は「R4-1 **または** R4-1' が定める値」であり、最初の更新なら 20 年と比べなければならない。
IR の修正: R4-2 を 2 つに割り、R4-2 は R4-1 を（10 年と比較）、R4-2' は R4-1' を（20 年と比較）上書きする。

「これ」のような**照応が、上書きされる側の Rule の値を指す**ことは、Semantic IR の `RuleValue` だけでは書けず、
上書き関係と組で決まる。これは層 2 の判定項目（ADR-0009）に「照応の先はどの Rule か」を足す根拠になる。

### 無矛盾の検査（効力の齟齬）— 3 件目のバグ

`lawean-verify::conflicts`: 同じ対象に相反する効果を与える 2 つの Rule（`Void` と `Preserve`、同じ属性への違う値の `Set`、同じ行為への義務と禁止）について、
**両方が同時に適用される世界があるか**を z3 に問う。効果の帰結は主張しない（主張すると両立しない世界は unsat になり矛盾が見えない）。
例外・特則（`overrides`）が正しく張ってあれば起きない。

手書き IR で走らせると、第4条の R4-1'（最初の更新は 20 年）と R4-2（10 年より長く定めたときはその期間）が
「最初の更新で 11〜19 年と定めた」世界で同時に適用されると出た。R4-1' が R4-1 だけを上書きし、R4-2 を上書きしていなかったため。
修正: R4-1' は R4-2 も上書きする（[art-04.md](03-examples/art-04.md)）。[07 の第4条のバグ](#検証が見つけた-ir-のバグ)、[10 の第26条のバグ](10-lean-semantics.md#7-検証が見つけた-ir-のバグ)に続く 3 件目。

逆に、第9条に「書面による特約は効力を妨げない」を overrides 無しで足すと、両方が適用される世界（書面による・この節に反する・不利）が反例として出る。「第九条の規定にかかわらず」= overrides を張ると消える（`tests/proofs.rs`）。

### 期間・効力・対象の齟齬は Z3 で検出できるか（2026-09-21 の整理）

| 齟齬 | いま | 足りないもの |
|---|---|---|
| 期間の性質（≥ 30 年、更新後 ≥ 10 年、比較） | **できる**（月数の Int の線形算術） | — |
| 期間の計算（起算点、初日不算入、月末、「一年前から六月前まで」） | できない（`Time` は不透明な Bool） | 暦を Int（日）に落とし民法 140〜143 条を式にする Temporal モデル。Z3 の線形算術で足りる |
| 施行日・経過措置（段階施行の順序、他法令の参照が違う意味になる区間） | Rust の `lawean-space`（TimingGap）と Lean の `scheduleOk` で構造的に | Rule ごとに効力の区間 [施行, 廃止) を持たせ「全ての時点 t で…」を Z3 に問う形。未 |
| 効力の齟齬（無効 vs 効力を妨げない、同じ属性に違う値、義務 vs 禁止） | **できる**（上の `conflicts`） | 主体は述語名に畳んであるので、主体違いは別の対象として見えない |
| 対象の齟齬（参照の指す先が違う、罰則が指す項がずれる） | Rust の Hane / Expected / CrossLaw で構造的に（公職選挙法の実例） | 意味の側で「罰則の対象 = 義務規定の対象」を見るには、主体と対象を層 2 で抽出する必要がある |
| 対象の齟齬（主体・定義語の範囲） | できない | 層 2（docs/11）。定義語の有効 scope は Resolved IR にあるので、scope 外の使用は規則で出せる |

## 制限（v0.1）

- 主体（subject）を無視している。「借地権者の義務」と「借地権設定者の義務」が同じ述語名なら衝突する
- 述語は不透明。「更新を請求した」と「契約の更新を請求する」は別変数（層 2 の同一性判定が要る）
- 時間は月数の整数。起算点・暦計算（民法 143 条）は未対応。第26条の「一年前から六月前まで」は不透明な Bool
- 手続（第4章）は対象外
