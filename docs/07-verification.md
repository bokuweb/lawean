# 07. Verification IR — Semantic IR を SMT に落として性質を検証する

状態: 実装（`crates/lawean-verify`）。z3 で手書き IR（第3・4・9・22条）の性質を証明・反証している。
同じ意味論を Lean の評価器として書き直した（[docs/10](10-lean-semantics.md)、[ADR-0016](adr/0016-lean-as-semantic-backend.md)）。ここの 6 性質は `lean/Lawean/Properties.lean` でも証明済み（Z3 と同じ結論）。証明と改正 × 意味の定理は Lean、反例探索は Z3 のまま併用する。ここの SMT 写像が Lean 版の仕様。

## 目的

「変換できる前提で、IR が検証に使えるか」を先に確かめる（[README](../README.md) の進め方 8）。
自動抽出（層 2）より前に、**IR の形が Z3 に素直に落ちるか**、**証明したい性質が書けるか**、**反例が法的に意味を持つか**を見る。

## 意味論（v0.1）

Semantic IR の各 Rule `R` に Bool `applies_R` を置く。

```
applies_R  ⇔  cond_R  ∧  ¬ applies_X  (X ∈ exceptions_of(R))
```

`exceptions_of` は `overrides` の逆引き（`lawean-resolve::ResolvedModel`）。ただし書き・特則・「かかわらず」はすべてこれで表す。
例外の例外は `applies_X` が自身の例外を含むので自然に連鎖する。

効果は `applies_R` を前件にした含意:

| Effect | SMT |
|---|---|
| `Set(attr, v)` | `applies_R ⇒ a:attr = v` |
| `Deem(fact)` | `applies_R ⇒ p:fact` |
| `Void(target)` | `applies_R ⇒ void:target` |
| `SameAs(R')` / `DeemAndApply{apply: R'}` | `applies_R ⇒ effect(R')`（R' の効果を R の前件で再主張） |
| `Exception(R')` | 追加なし（`overrides` が担う） |
| それ以外 | `applies_R ⇒ eff:R`（Bool の印。性質からは「その効果が生じた」としてだけ参照できる） |

式:

| Expr / Value | SMT |
|---|---|
| `Pred(name, args)` | Bool 定数 `p:name(args)`。**述語は不透明**。同じ名前・引数なら同じ変数 |
| `Cmp(a, op, b)` | Int の比較 |
| `Duration` / `Period` | 月数の Int リテラル（年 × 12）。日・週・時は v0.1 では未対応 |
| `Var(x)` | Int 定数 `v:x`。属性 `a:x` と**同じ名前空間**（「存続期間」を条件で参照すれば R3 が定めた値になる） |
| `RuleValue(R)` | R の `Set` が定める値をインライン展開 |
| `Unknown(...)` | 自由な Bool / Int 定数。評価概念（「不利」「正当の事由」）はこれで自由変数になる |
| `Ref(Rule R)` | `applies_R` |
| `Time(...)` | v0.1 では不透明な Bool |

性質は同じ Expr で書き、`(assert (not P)) (check-sat)` で **unsat なら証明、sat なら反例**（モデルを表示）。
評価概念を含む性質には**補題**（人が書く追加の assert）を添える。補題は IR ではなく検証入力であり、Provenance を持たない。

### 検証が見つけた IR のバグ

[art-04.md](03-examples/art-04.md) の手書き IR で、ただし書き R4-2 の条件を `当事者が定めた期間 > RuleValue(R4-1)`（= 10 年）と書いていた。
z3 は「最初の更新で 15 年と定めた」を反例に出した: 15 > 10 なので R4-2 が適用され、更新後の期間が 15 年になり 20 年を下回る。
原文の「これより長い期間」の「これ」は「R4-1 **または** R4-1' が定める値」であり、最初の更新なら 20 年と比べなければならない。
IR の修正: R4-2 を 2 つに割り、R4-2 は R4-1 を（10 年と比較）、R4-2' は R4-1' を（20 年と比較）上書きする。

「これ」のような**照応が、上書きされる側の Rule の値を指す**ことは、Semantic IR の `RuleValue` だけでは書けず、
上書き関係と組で決まる。これは層 2 の判定項目（ADR-0009）に「照応の先はどの Rule か」を足す根拠になる。

### 無矛盾の検査（効力の齟齬）— 3 件目のバグ

`lawean-verify::conflicts`: 同じ対象に相反する効果を与える 2 つの Rule（`Void` と `Preserve`、同じ属性への違う値の `Set`、同じ行為への義務と禁止）について、
**両方が同時に適用される世界があるか**を z3 に問う。効果の帰結は主張しない（主張すると両立しない世界は unsat になり矛盾が見えない）。
例外・特則（`overrides`）が正しく張ってあれば起きない。

手書き IR で走らせると、第4条の R4-1'（最初の更新は 20 年）と R4-2（10 年より長く定めたときはその期間）が
「最初の更新で 11〜19 年と定めた」世界で同時に適用されると出た。R4-1' が R4-1 だけを上書きし、R4-2 を上書きしていなかったため。
修正: R4-1' は R4-2 も上書きする（[art-04.md](03-examples/art-04.md)）。[07 の第4条のバグ](#検証が見つけた-ir-のバグ)、[10 の第26条のバグ](10-lean-semantics.md#7-検証が見つけた-ir-のバグ)に続く 3 件目。

逆に、第9条に「書面による特約は効力を妨げない」を overrides 無しで足すと、両方が適用される世界（書面による・この節に反する・不利）が反例として出る。「第九条の規定にかかわらず」= overrides を張ると消える（`tests/proofs.rs`）。

### 期間の計算で Z3 が直感を正した例

`tests/temporal.rs` で「初日算入と不算入は常に 1 日ずれる」と書いたら反例が出た。閏日 2020-02-29 から一年は、算入だと応当日（2021-02-29）が無く月末 02-28 に満了し（第143条第2項ただし書き）、不算入（起算 03-01 → 応当 2021-03-01 の前日 = 02-28）と一致する（差 0）。逆に 2019-02-28 から一年は差 2 日（閏日をまたぐ）。正しい主張は「差は 0〜2 日」。
起案でよくある「六月を経過する日」と「六月を経過した日」の 1 日の差、「一年前から六月前まで」を逆に書いた空の区間も、全ての日付について判定できる。

### 期間・効力・対象の齟齬は Z3 で検出できるか（2026-09-21 の整理）

| 齟齬 | いま | 足りないもの |
|---|---|---|
| 期間の性質（≥ 30 年、更新後 ≥ 10 年、比較） | **できる**（月数の Int の線形算術） | — |
| 期間の計算（起算点、初日不算入、月末、「一年前から六月前まで」） | **できる**（`temporal`: 日付 = (年, 月, 日) の Int、民法 140・141・143 条を `define-fun` で。`tests/temporal.rs`） | 第142条（休日）と、`TimeCond` からの自動展開（今は API を手で呼ぶ） |
| 施行日・経過措置（段階施行の順序、他法令の参照が違う意味になる区間） | **できる**（`validity`: 効力の区間 [施行, 廃止) と「参照先が正しい区間」を与え、参照元が効力を持つのに参照先が違う日を反例に。公職選挙法の 3 年の空白、段階施行の TimingGap） | 廃止・経過措置の区間はまだ手で与える |
| 施行期日（附則第一条「公布の日から起算して一年を超えない範囲内において政令で定める日」と、実際の施行日） | **できる**（下の「時間表現の抽出」。附則を規則で読み、公布日から暦で許容区間を出し、`lawean-check` の `Enforcement` が施行日を突き合わせる。Z3 側は `enforcement`: 同じ区間を暦の `define-fun` で解き、Rust の暦と一致することをテストで確かめる） | 「新非訟事件手続法の施行の日から施行する」のように他法令の施行日に依るもの |
| 効力の齟齬（無効 vs 効力を妨げない、同じ属性に違う値、義務 vs 禁止、**できる vs 禁止**、**みなす vs 無効**） | **できる**（上の `conflicts`。組は効果の型で列挙し、特則の `overrides` が張ってあれば同時適用は消える） | 主体は述語名に畳んであるので、主体違いは別の対象として見えない |
| 空振り（罰則などの対象を定めたが、例外規定を差し引くと対象が存在しない。条件自体が矛盾） | **できる**（`vacuous`: applies(R) = 条件 ∧ ¬applies(例外) が unsat なら空振り。`tests/proofs.rs` の R-pen: 「三十年以上」の罰則に「二十年以上はこの限りでない」を張ると unsat、「五十年以上」なら 30〜50 年の反例が出る） | 条件が同じ変数で書けていること（数値・同じ述語）。別の語で書いた同じ事柄は層 2 の同一性判定 |
| 対象の齟齬（参照の指す先が違う、罰則が指す項がずれる） | Rust の Hane / Expected / CrossLaw で構造的に（公職選挙法の実例） | 意味の側で「罰則の対象 = 義務規定の対象」を見るには、主体と対象を層 2 で抽出する必要がある |
| 対象の齟齬（主体・定義語の範囲） | できない | 層 2（docs/11）。定義語の有効 scope は Resolved IR にあるので、scope 外の使用は規則で出せる |

### 時間表現の抽出（規則。2026-09-21）

期間・時点・施行の記述は日本語だが、法制執務で用語が統一された**閉じた語彙**なので規則（層 1、[ADR-0008](adr/0008-hybrid-extraction.md)）で取る。`lawean-extract::temporal::time_exprs` が 1 文から位置つきの `TimeExpr` を返す:

| 形 | 例 | `TimeKind` |
|---|---|---|
| 事象からの期間 | 「借地権の設定後三十年」「〜の日から起算して六月」 | `Period { event, dur, counted_from_first }` |
| 経過（満了日・翌日） | 「六月を経過した日」「三月を経過することによって」 | `Elapsed { event, dur, boundary }` |
| 期限 | 「二月以内に」「一年を超えない範囲内」 | `Within` |
| 窓 | 「期間の満了の一年前から六月前までの間」 | `Window { event, from_before, to_before }` |
| 前 | 「一年前までに」「少なくとも六月前に」 | `Before` |
| 比較・値 | 「三十年以上」「十年とする」 | `Compare` / `DurationValue` |
| 暦の日・元号日付・周期 | 「四月一日」「令和三年九月一日」「三年ごとに」 | `Calendar` / `EraDate` / `Every` |
| 施行期日 | 「公布の日から起算して一年を超えない範囲内において政令で定める日から施行する」 | `Enforcement` |

対象外として区別するもの: 利率（「年一割」）、法令番号（「令和三年法律第三十七号」）、読替え規定の中の字句（「「三日」とあるのは」）。

被覆（数詞 + 年/月/日/週 のうち、裸の `Duration` で終わらず構造で取れた割合。`cargo run -p lawean-extract --example temporal -- <xml>`）:
借地借家法 100%（40/40）、公職選挙法 87%（543/623）、民法 89%（224/253）。残りは「同項の期間」のように先行詞が文をまたぐものと表の欄で、層 2 の対象。

**附則 → 施行日の許容区間**（`lawean-extract::suppl`）: 改正法の附則第一条は決まった形（本文 + 各号の範囲欄・日付欄）で、範囲欄は改正法の条の列挙（「第五十九条から第六十三条まで」、「並びに」で区切った群、「附則」が付けば附則の条。「第五条中人事訴訟法第三十五条」の第三十五条は被改正法の条なので除く）。公布日は `AmendLawNum`「令和四年五月二五日法律第四八号」から。許容区間は民法第143条の暦（`calendar`。Z3 の `temporal` と同じ規則）で:

| 附則 | 区間 |
|---|---|
| 公布の日から | 公布日 |
| 令和三年九月一日から | その日 |
| 公布の日から起算して n 月を経過した日から | 満了日の翌日（= 応当日） |
| 公布の日から起算して n 月を超えない範囲内において政令で定める日から | 公布日 〜 満了日（応当日の前日） |

実例（`fixtures/cases`）: 令和3年法律第37号 第35条は附則第一条第四号「一年を超えない範囲内」→ 2021-05-19〜**2022-05-18**、e-Gov の施行日は上限ちょうど。令和4年法律第48号は借地借家法を**附則**第73条で改め、第二号「九月を超えない範囲内」→ 〜2023-02-24、e-Gov は 2023-02-20。第74条は本文「四年を超えない範囲内」→ 〜2026-05-24、現行 2026-05-21。失敗例 `enforced-out-of-range`（施行日 2022-06-01）は `Enforcement` で落ちる。

### 罰則（2026-09-22）

罰則は最も語彙が閉じている。`lawean-extract::penalty` が規則で (対象規定への参照, 行為, 刑) の三つ組に落とす:
「次の各号のいずれかに該当する者は、一年以下の禁錮又は三十万円以下の罰金に処する。」+ 号「第百四十二条の四第六項の規定に違反して同項に規定する事項を表示しなかつた者」。
「A の規定に違反して X した者又は B の規定に違反して Y した者」は区切りで分け、括弧書き（「（…において準用する場合を含む。）」）は準用の文脈として対象から外す。公職選挙法で罰則 84、対象 79、参照はすべて解決。

**空振りの検査**（`mismatches`）: 対象規定の本文（+ 条の見出し）に罰則の行為の語（「表示」「戸別訪問」。送り仮名は無視、複合語は末尾 2 字も可）が無い、または対象規定の効果種別が定義・みなし・適用・施行の類しかない。

| リビジョン | 空振り |
|---|---|
| 公職選挙法 2018-06-20（平成30年法律第75号の前） | 0 |
| 2018-10-25（同法の後。第142条の4の繰り下げで第244条の「第六項」がずれた） | **1**: 第244条第1項第2号の2「…表示しなかつた者」→ 第142条の4第6項（送信の禁止）に「表示」が無い |
| 2021-06-02（令和3年法律第51号で訂正） | 0 |

つまり 2018 年の実際の改正漏れは、**改め文を見ずに改正後の本文だけで**出る（ハネの検査は改め文が要る）。`lawean-check` の `Penalty` は改正前後で空振りを比べ、改正で生じたものを Fail、改正前から在るものを Warn にする。

見ていないもの: 主体の齟齬（義務の主体 ≠ 罰則の主体。層 2）、同じ行為への 2 罰則の同時適用（`conflicts` の型で、罰則の条件を `Expr` に落とせば動く）、法定刑の範囲（線形算術、自明）。

## 制限（v0.1）

- 主体（subject）を無視している。「借地権者の義務」と「借地権設定者の義務」が同じ述語名なら衝突する
- 述語は不透明。「更新を請求した」と「契約の更新を請求する」は別変数（層 2 の同一性判定が要る）
- 意味の性質では時間は月数の整数。暦計算（`temporal`）と時間表現の抽出（上）はあるが、`TimeCond` から日付の制約への自動展開はまだ（第26条の「一年前から六月前まで」は性質の側では不透明な Bool）
- 手続（第4章）は対象外
