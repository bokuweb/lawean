# 14. 当てる側の精度 — 衆議院の改め文を e-Gov の版で確かめる

改め文を**読める**（`parse_units`、平成以降 100%）ことと、読んだ操作を法令に**当てて正しい本文になる**ことは別である。
読み違い（字句の閉じ方、位置の先行詞）は、読めた率には出ない。そこで、衆議院の制定法律の改め文を
e-Gov の**改正前の版**に当て、e-Gov の**改正後の版**と突き合わせる。

## 1. しくみ

```
cargo run --release -p lawean-amend --example bench_apply -- list ~/.cache/lawean/shugiin/txt --since 19890108 --out units.tsv
python3 tools/fetch_egov_revisions.py units.tsv pairs.tsv --xml-since 20170101
cargo run --release -p lawean-amend --example bench_apply -- run ~/.cache/lawean/shugiin/txt --pairs pairs.tsv --out result.tsv
```

1. **単位の一覧**（`bench_apply list`）: 改正単位ごとに、改正法の法令番号（ページの 14 桁から。「令和三年法律第三十七号」）と
   被改正法の法令番号（題名の後の括弧書き）を出す
2. **版の組**（`tools/fetch_egov_revisions.py`）: e-Gov API v2 で法令番号 → 法令 ID、改正履歴（`law_revisions`）を引き、
   被改正法の版のうち**その改正法による版をすべて候補**にする。候補は（その版の直前の版, その版）と、
   （最初の版の直前の版, 最後の版）（単位の中の段階施行）。版の本文は gzip で `~/.cache/lawean/egov/rev/` に持つ
   - 改正法は**法令番号**で照らす。法令 ID は閣法（`AC0000000…`）・衆法（`AC0100000…`）・参法（`AC1000000…`）で形が違う
   - e-Gov は混雑すると 200 で HTML の「ページが見つかりません」を返す。XML でない応答はやり直す
3. **突き合わせ**（`bench_apply run`）: 候補ごとに `apply_unit` で当て、本則と原始附則の条・項ごとの本文、目次、
   **項の中の表**（読替え表・税率表）と**別表**の本文を比べる。一番良い候補を結果にする
   - `match`: 一致。`match_trivial`: 比べる部分が直前の版から変わらない（当てたことの確かめにならない。率から外す）
   - `mismatch`: 当てられたが本文が違う。**読み違い・当て違いの検出**
   - `mismatch_other`: 違いがこの単位の触らない条にだけあり、そこは e-Gov の版で変わっている（同じ版に入った別の改正の分）
   - `unsupported` / `apply_error`: 当てられない（未対応の操作、字句・位置が見つからない）
   - `match_staged`: **段階施行**（附則で文ごとに施行日が違う）。同じ改正法ページで同じ法律を改める単位の文をまとめ、
     改正法の版ごとに、その版に近づく文だけを当てる（`stage_match`）。一致した版で使った文を確かめたとし、
     文が全部確かめられた単位を数える。文で確かめられなければ操作ごとにも試す（「…の改正規定（「A」を「B」に改める部分に限る。）」）。
     附則の施行期日は読まない。どの文がどの版に入ったかは、本文の変化で確かめる
   - 比べる前に字形（JIS2004 の「塡」「剝」…）と括弧番号（「(1)」→「（１）」）を揃える
4. **identity patch の経路**（`ident` の列）: 同じ単位を `ident::bind` で発射台に束縛し、Lean の `Ident.applyUnit` の写し
   （`ident::apply_unit`）で当てて e-Gov の版と比べる。**証明した意味論が、実データで文書への適用と揃うか**を見る

## 2. 結果（2026-09-24）

e-Gov の改正履歴は 2017 年ごろからなので、比べられるのは主に 2017 年以降の単位（平成以降 13,480 単位のうち 3,620）。
比べるのは本則・原始附則・目次に加えて、項の中の表と別表の本文（最初の計測より厳しい）。

| | 最初（#26） | いま |
|---|---|---|
| 比べた（`match_trivial` を除く） | 3,600 | 3,620 |
| **一致**（`match` + `match_staged`） | 2,329（64.7%） | **2,464（68.1%）** |
| 　うち段階施行の突き合わせで一致（`match_staged`） | — | 94 |
| 不一致（`mismatch`） | 383 | 353 |
| 別の改正が混ざる（`mismatch_other`） | 102 | 76 |
| 当てられない（`apply_error` / `unsupported`） | 595 / 191 | 590 / 137 |
| e-Gov に版が無い（`no_revision`、主に 2016 年以前） / 被改正法が e-Gov に無い（`no_target`） / 直前の版が無い（`no_base`） | 7,406 / 1,540 / 735 | 同じ |

年ごと（公布年、比べた単位のうちの一致）: 2017 年 71.8%、2018 年 52.6%、2019 年 62.9%、2020 年 55.6%、2021 年 63.0%、
2022 年 82.9%（刑法等の「懲役」「禁錮」→「拘禁刑」の単純な字句の改正が多い）、2023 年 67.9%、2024 年 48.9%、2025 年 56.7%。
全体の計測は 27 分（M 系の Mac、1 スレッド）。

**identity patch の経路**は、一致した 2,370 単位（`match`）のうち 2,318（97.8%）で e-Gov の版と一致した。
揃わないのは、目次を新しく置く改正・目次と章名を付ける改正（id の世界に目次を作る操作が無い）などの id の表し方の限界。

**当てられないものの多く**は、字句・条・項が直前の版に無いもの。調べた見本では、ほとんどが版の組の問題だった
（段階施行で、その文の入る版の直前の版が候補に無い。間の改正が e-Gov の改正履歴に無い。e-Gov が別の法律の版として持つ）。

## 3. ベンチで見つけて直したもの

- **項番号を書かない古い法律**（学校教育法など e-Gov の `OldNum="true"`）に加える項: 衆議院のページは番号を書かない。
  番号の無い文を項として作り、位置の番号に振り直す（条を加えるときも）
- **本則から番号の続く附則の条**（労働基準法 附則の「第百三十八条」）: 改め文は「附則」を冠さない。本則に無ければ原始附則から探す
- **範囲の削除の条**（e-Gov の Num「150:151」「第百五十条及び第百五十一条　削除」）: 中の条を分けて当てる
- **条の前に節名・章名を置く**（「第二章中第三条の前に次の節名を付する」「…の前に次の節名及び二条を加える」）: 条から次の容器までを包む
  （同じ種類の容器の中なら分ける）。identity patch では条の追加（id の世界）と題名だけの包み（文書の側）に分ける
- **表の行の中の位置**（「六の項第六号中」「(に)項第一号中」）: 行の中に字句が一つだけなら当てる（複数なら未対応のまま）
- **別表の題名の照合**: e-Gov の題名「別表第一　在外公館の名称及び位置」は空白を詰めると「別表第一在外公館…」。詰めた題名で照らす
- **表記**: 目次の範囲「−」→ e-Gov の「―」、常用漢字の字形「填」→「塡」、字句と加える本文の「(1)」→「（１）」
- **誤記表**: 改め文の字下げの崩れ 1 件（加える条文と同じ字下げ）
- **目次の字句の続く置換**（「「第五章…」を「第五章…第六章…」に、「第六章」を「第七章」に」）: 同じ文で先に加えた字句に印を付け、
  後の置換から守る（本文の置換と同じ）。先に加えた「第六章」を「第七章」に変えてしまっていた
- **表の本文**: 条・項の中の表の全部・行の差し替えと行の追加を当てる。比べる本文に表と別表を入れた
- **目次と章名を付ける改正**（「題名の次に次の目次及び章名を付する」）: 目次を組み、最初の条から章で包む
- **範囲を一つの条に替える改正**（「第九百三十条から第九百三十二条までを次のように改める」+「…まで　削除」）: 並びの間の条を差し替える
- **表記**: 全角の括弧の振り仮名（「口蹄（てい）疫」「禁錮（こ）」。e-Gov は Ruby）を落とす。数の位取りの「,」→「，」
- **落ちていた所**: 同じ文の先の操作で項が減ったときの項の引き当て（範囲外）、差分の表示の文字の切り方

## 4. 残り（次の手）

- **版の組**: 段階施行で文の入る版の直前の版を候補に入れる（改正法の版だけでなく、間の別の法律の版の後も試す）
- **表の中**（関税率表の号 `別表第N・N号`、俸給表の欄）と、加える別表・表の行の形（「表に「…」の項が無い」）
- **目次の字句**（32）: 目次の行の組み方の違い
- `mismatch` 353: 読み違い・当て違いの候補。`first_difference` の前後で見る
