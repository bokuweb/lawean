改正法を書いて検査する playground

発射台（改正前の法令）を選び、改め文と附則を書き、公布予定日・施行日を与えて検査する。判定はブラウザ内の WASM（溶け込みは Lean の証明済み applyUnit）。実例のケース集はこちら

手元の e-Gov XML（law_data API の応答）を読ませることもできる:

発射台を選ぶと本則の条が出る。

読める形: 第N条[第M項][第K号]中「A」を「B」に改める、「A」の下に「B」を加える、「A」を削る、第N条に次の一項を加える、第N条第M項の次に次の一項を加える、第N条の次に次の一条を加える、第N章に次の一条を加える、第N条を次のように改める、第N条中第P項を第Q項とし、第A項から第B項までをK項ずつ繰り下げ、第N条[第M項]を削る、目次中「A」を「B」に改める、後段として次のように加える。加える条文は次の行に全角スペース 1 つでインデント。

読める形: 公布の日から施行する、令和N年M月D日から施行する、公布の日から起算してN年を経過した日から、公布の日から起算してN年を超えない範囲内において政令で定める日から、令和N年M月D日までの間において政令で定める日から、ただし書き ただし、第N条の改正規定は、公布の日から施行する。

発射台を選び、改め文を書いて「検査する」。
