# 0008. 自然文 → Semantic IR の抽出戦略: 定型は規則、非定型は LLM + 検証、確度を必ず持つ

状態: proposed

## 文脈

「契約の条件にかかわらず」のような表現は無数にあり、規則ベースで日本語を解析しきれるのか、
形態素解析・係り受け解析が要るのではないか、という問い（2026-09-20）。

法令の日本語は一般の日本語より大幅に定型化されている（法制執務の用語統一）が、条件部（要件）の中身は開放的で、
「正当の事由」「相当」「不相当となったとき」のような評価概念も多い。全自動で正しい IR を出すことは目標にできない。

実測（借地借家法 + 民法）:

- 「〜にかかわらず」約 60 件は、直前の名詞で **3 パターン**に完全に分かれる（「〜の規定に」= Rule 上書き / 「契約の条件・特約に」= 契約に優先 / 「〜かどうか・の有無に」= 譲歩）
- 条項参照 233 件（借地借家法本則 + 原始附則）は、規則ベースで **未解決 0**、他法令 36 件（うち推定 3 件）
- 文末の効果表現（とする / しなければならない / してはならない / することができる / みなす / 推定する / 適用しない / この限りでない / 準用する / 無効とする / 従前の例による）は閉じた語彙。
  `lawean-extract` の 20 種の分類で、借地借家法の平叙文 211（定義欄を除く）のうち 97% を分類。残り 6 文は号に列挙された名詞句

## 判断

抽出を 3 層に分け、各層の出力に `Provenance.by` と `confidence` を必ず付ける。

| 層 | 対象 | 手段 | confidence |
|---|---|---|---|
| 1. 構造・参照・効果種別 | ただし書き（XML の `Function`）、条項参照、定義規定（`Column`）、「〜にかかわらず」の 3 分類、文末の効果表現、「〜に限る」「〜場合において」の節境界 | 規則（正規表現 + 位置索引）。`lawean-resolve` + `lawean-extract`。出力は条件の中身が `Unknown(Unparsed)` の**骨組み Rule** | 骨組みは Medium。効果種別・参照・overrides は High 相当 |
| 2. 要件・効果の構造化 | 条件式（And / Or / 述語と引数）、主体、期間・金額の値、Rule の分割（括弧書き・対称な 2 Rule） | LLM に IR スキーマで出力させ、層 1 の結果と `validate` で突き合わせる。矛盾したら `Unknown(Unparsed)` | Medium。人が確認して High に上げる |
| 3. 評価概念・解釈 | 正当事由、相当、不利、判例による形成権の効果 | 抽出しない。`Unknown(Intentional)` / `Interpretation` として人が書く | — |

形態素解析・係り受け解析は**必要になった箇所で導入する**（前提にしない）。想定される用途は、定義語の出現位置の検出（層 1 の精度向上）と、
LLM 出力の裏取り（「この述語の主語は本当にこの名詞か」）。Rust から使える形態素解析器（vibrato / lindera）は軽いので層 1 に足しやすい。
係り受けは Rust 生態系が薄く、Python（GiNZA 等）との連携コストを払う価値が層 2 で出るかは、LLM の精度を見てから決める。

## 理由

- 層 1 は定型なので規則で十分であり、規則の方が**説明可能で再現性がある**（同じ入力に同じ出力。改正の差分検出に必須）
- 層 2 のバリエーションは LLM の方が規則より圧倒的に広く拾える。ただし LLM は参照や番号を間違えるので、層 1 の結果を正として突き合わせる
- 層 3 は言語処理の問題ではなく法解釈の問題。どの解析器でも解けない
- 「正しく parse しきる」ではなく「**どこまで正しいかを IR 自身が言える**」ことを目標にする。それが ADR-0001（Unknown の種類）と ADR-0005（複数解釈）の帰結

## 結果

- 層 1 のカバレッジ（参照解決率、効果表現の分類率）と、層 2 の Unknown 率を継続的に測る。fixture に対する数値をテストに固定する
- 層 2 の LLM 出力は `Author::Llm(model)` で必ず区別し、人の確認を経るまで High にしない
- 層 1 で拾えない定型が見つかったら規則を足す（今回の「同条」「列挙の引き継ぎ」「括弧書きをまたぐ列挙」がその例）
- 係り受け解析の導入は別 ADR で判断する
