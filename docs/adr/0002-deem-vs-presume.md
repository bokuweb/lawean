# 0002. 「みなす」と「推定する」を分ける

状態: accepted

## 文脈

日本法では「みなす」（擬制。反証を許さない）と「推定する」（反証を許す）が明確に区別される。
どちらも「事実 X を Y として扱う」なので、1 つの Effect に潰したくなる。

## 判断

`Effect::Deem(Fact)` と `Effect::Presume(Fact)` を別にする。

## 理由

- 検証上の意味が違う。`Deem` は公理として追加できる。`Presume` は「反証がない限り」という条件付きで、反証の Fact が別途要る
- 混ぜると Lean で証明した性質の意味が変わる（「反証がある場合」を見落とす）

## 結果

- `Presume` には `rebuttable_by: Option<Expr>` 相当が要るかもしれない。03 で推定規定の例が出てから決める
- 「みなして〜を適用する」（読み替え + 適用）は `Deem` の変種ではなく別の合成。[art-05.md](../03-examples/art-05.md) 第3項

## 関連

借地借家法第5条（みなす）、民事訴訟法第228条第4項（推定）
