# 民法第140〜143条（期間の計算）— Temporal モデルの前提

状態: 第140・141・143条を Z3 の式にした（`crates/lawean-verify/src/temporal.rs`、docs/07）。ここの例（03-15 + 1 年、01-31 + 1 月、2000-04-01 + 30 年）はテストで固定。第142条と遡りの規則は未（遡りは応当日で逆算する扱い）

借地借家法の「三十年」「一年前から六月前まで」「通知の日から六月」はすべて民法第1編第6章（第138〜143条）で計算される。
借地借家法の IR には含めないが、**Temporal 型の意味論の仕様書**としてここに置く。

## 原文

> 第138条　期間の計算方法は、法令若しくは裁判上の命令に特別の定めがある場合又は法律行為に別段の定めがある場合を除き、この章の規定に従う。
> 第140条　日、週、月又は年によって期間を定めたときは、期間の初日は、算入しない。ただし、その期間が午前零時から始まるときは、この限りでない。
> 第141条　前条の場合には、期間は、その末日の終了をもって満了する。
> 第142条　期間の末日が日曜日、〜休日に当たるときは、その日に取引をしない慣習がある場合に限り、期間は、その翌日に満了する。
> 第143条　1. 週、月又は年によって期間を定めたときは、その期間は、暦に従って計算する。
> 　　　　　2. 週、月又は年の初めから期間を起算しないときは、その期間は、最後の週、月又は年においてその起算日に応当する日の前日に満了する。
> 　　　　　　ただし、月又は年によって期間を定めた場合において、最後の月に応当する日がないときは、その月の末日に満了する。

## Temporal 型に求められること

```rust
struct Duration { length: u32, unit: Unit }          // Unit = Hour | Day | Week | Month | Year
struct Period {                                        // 具体的な期間
    from: Event,                                       // 起算点となる事象（契約日、通知の日、満了日 …）
    length: Duration,
    direction: Forward | Backward,                     // 「〜の日から」/「〜の一年前」
}
struct Window { from: Period, to: Period }             // 「一年前から六月前までの間」
enum PeriodValue { Definite(Period), Indefinite }      // 「期間の定めがない」
```

**計算規則（民法から）**

| 規則 | 条 | 実装 |
|---|---|---|
| 初日不算入 | 140 本文 | `from` が日単位以上なら起算日 = event 日 + 1 |
| 午前零時開始なら初日算入 | 140 ただし書き | `event` が日の始まりなら +0 |
| 末日の終了で満了 | 141 | 満了時刻 = 末日 24:00 |
| 暦による計算 | 143-1 | 月・年は暦月・暦年で数える（30 日 × n ではない） |
| 応当日の前日に満了 | 143-2 本文 | 起算日 2020-03-15 + 1 年 → 2021-03-14 終了 |
| 応当日が無ければ月末 | 143-2 ただし書き | 2020-01-31 起算 + 1 月 → 2020-02-29 |
| 休日なら翌日（取引しない慣習がある場合） | 142 | `Unknown(Intentional)`。v0.1 では無視し、注記だけ残す |
| 特別の定め優先 | 138 | 借地借家法に期間計算の特則は無い（要確認） |

## 論点

- **「一年前から六月前まで」の遡り計算**に民法は直接触れていない（第140条は起算する場合）。判例・実務では
  「満了日の応当日」を基準に逆算する。Backward の計算規則は `Unknown(Ambiguous)` にして、Z3 では区間として扱う
- 「三十年」の起算点は借地権の**設定日**（契約日）。初日不算入なので 2000-04-01 契約 → 起算 04-02 → 2030-04-01 終了。
  この 1 日のずれが Lean での証明対象になりうる（「更新前の期間と更新後の期間が連続する」など）
- **v0.1 の Temporal は民法 140・141・143 だけ実装**する。142 と Backward は Unknown。
  Z3 に渡すときは日数に展開せず、`year/month/day` の整数三つ組で応当日計算を制約として書く
- 民法第138〜143条自体を Semantic IR にする必要はない（メタ規則）。Temporal 型の**実装仕様**として Rust に直接書く。
  ただし Provenance として「この計算は民法第143条第2項による」を残せるようにする
