# 13. 先行改正との競合 — 起草後・施行前に別の改正が施行されるとき

改正法 X は、起草した時点の法令の状態（起草時の発射台）に対して書かれる。しかし X が実際に当たるのは、
**X の施行日の直前の状態**である。公布から施行までに別の改正 B が施行されていれば、X は B の後の本文に当たる。
B が X より後に公布されたなら、X を書いた人は B を知らない。

## 1. 何が起きるか

| 型 | 例 | どう出るか |
|---|---|---|
| **空振り** | X が「「A」を「B」に改める」と書いた字句 A を、B が先に書き換えた | X の改正規定が当たらない。溶け込めない |
| **別の項を指す（誤爆）** | X が「第N条第三項中…」と書いたが、B が第2項を挿入して旧第3項は第4項になった | X が違う項を改める。溶け込みはするので気づきにくい |
| **加える本文の参照のずれ** | X が新設する条の本文に「第二十八条第五項」と書いたが、B が第28条に 2 項を挿入した | X の施行後、参照が別の項を指す（ハネと同じだが、手当てするのは既存の本文ではなく **X の改め文そのもの**） |
| **同じ項を両方が改める** | X と B が同じ項の別の字句を改める | 順序で結果が変わる。後に施行される方が先の方の本文を前提に書かれていなければならない |

対処は 3 つ:
- **独立なら何もしない**: X と B が触る項が交わらなければ、順序を入れ替えても結果は同じ（Lean `applyUnit_comm`）。調整規定は要らない
- **改正法の改正**: 後から公布される B の側で、未施行の X の改め文を改める（「○○法の一部を改正する法律の一部を次のように改正する」）
- **調整規定**: 施行順が確定しないとき、「A の施行の日が B の施行の日前である場合には…とあるのは…とする」で両方の順序に備える（[参議院法制局「調整規定」](https://houseikyoku.sangiin.go.jp/column/column059.htm)、[同「公布後施行前の法律の改廃」](https://houseikyoku.sangiin.go.jp/column/column026.htm)）

## 2. 実例

### 2.1 令和2年法律第62号 第2条 ← 令和3年法律第37号（`r2-62-vs-r3-37-stale`）

- X = 令和2年法律第62号（マンション管理適正化法・建替え円滑化法改正、公布 2020-06-24）第2条。建替え円滑化法（414AC0000000078）に敷地分割事業の章を加える。施行 2022-04-01
- B = 令和3年法律第37号（デジタル社会形成整備法、公布 2021-05-19）。区分所有法第63条に第2項を、建替え円滑化法第28条に第4・5項を挿入し、同法第124条第3項を書き換える。施行 2021-09-01 = **X より後に公布され、先に施行**

令3-37 は附則第63条で X の改め文そのものを 3 箇所改めた（[衆議院 制定法律](https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/housei/20420210519037.htm)）:

| 令3-37 附則第63条 | 型 | lawean の `Stale` 検査 |
|---|---|---|
| 第124条第3項の改正規定中「「、区分所有法第六十三条第五項」を「、同条第五項」に、」を削り | 空振り（B が第124条第3項を書き換えたので字句が無い） | 起草時の版（2020-06-24）には当たり、施行時の版（2022-04-01）には当たらない: 「第124条第3項 に「、区分所有法第六十三条第五項」が無い」 |
| 第178条に係る部分中「第二十八条第五項」を「第二十八条第七項」に改め | 加える本文の参照のずれ | 「第二十八条第五項」は起草時の第28条第5項「第九条第一項の規定による認可を受けた者は…」を指すが、施行時の版ではその項は第7項。手当て「第二十八条第五項」→「第二十八条第七項」 |
| 第180条第4項に係る部分中「第四項まで及び第六項」を「第六項まで及び第八項」に改め | 同上 | 「第四項」→「第六項」（本文も変わっている）、「第六項」→「第八項」 |

3 つとも、起草時の版と施行時の版の 2 つを与えるだけで**生成した手当てが実物と一致する**。
（第182条の書き換えは電磁的方法の追加という実質改正で、この型ではない。）

### 2.2 公布順と施行順が逆の組（`r4-68-takken-commutes`、Lean `Pending.lean`）

令和4年法律第68号（拘禁刑への整理法、公布 2022-06-17、施行 2025-06-01）は多数の法律の「懲役」を改める。
その間に、後から公布された改正が先に施行された法律は多い（宅建業法: 令5-79 が 2024-04-01、令6-53 が 2025-04-01。古物営業法: 令5-79 が 2024-04-01）。
e-Gov の `law_revisions` で、公布順と施行順が逆の組はこの型の候補である。

これらは触る項が交わらないので**独立**で、順序を入れ替えても同じ結果になる。Lean では、改め文の無い先行改正を
2 つのリビジョンの差から id の操作列にし（`ident::derive_unit`）、第98条の束縛と `IndependentUnits` であることを `native_decide` で確かめ、
`applyUnit_comm` で「どの発射台に対しても順序を入れ替えられる」を得る（`Pending.lean`: `independent_art98_intervening`、`art98_intervening_commute`、両方の順で e-Gov の 2025-06-01 版に達する）。
実際にも調整規定は置かれていない。

### 2.3 未施行の改正の施行後を前提に書く（`r5-53-art125-future-base`）

令和5年法律第53号（公布 2023-06-14）第125条は借地借家法第61条を改めるが、その本文は令和4年法律第48号 第74条（2026-05-21 施行、当時は未施行）が
書き換えた後のものを前提にしている。公布時の版には当たらず、施行時の版に当たる。施行順が逆になれば空振りするので、順序が確定していなければ調整規定が要る（実際は令4-48 の施行が先で問題無かった）。`Stale` は Warn。

### 2.4 その他の実例（参議院法制局のコラムから）

- 平成30年法律第33号 附則第29条が改める予定だった法律の題名を、後から公布された平成30年法律第94号が施行前に変えた → 平30-94 附則第30条第2号で引用を新題名に直した
- 平成24年法律第27号（労働者派遣法の題名変更）と平成24年法律第53号（暴力団対策法改正）→ 平24-53 附則第31条第2項に「A 法の施行の日が B 法の施行の日前である場合」の調整規定

## 3. 検出（`lawean-check` の `Stale`）

入力: 施行時の発射台 `base`（e-Gov は未施行のリビジョンも返すので、施行日の直前の版が取れる）と、起草時の発射台 `base_draft`。他法令も同様に 2 つの版を渡せる。

1. X を両方に束縛する（`ident::bind`）。起草時に当たり施行時に当たらなければ**空振り**（Fail）。逆なら「先行改正の施行後を前提」（Warn）
2. 両方に当たるなら、同じ順番の `replace` が指す項の本文を比べる。違えば**別の項を指す**か、**同じ項を B も改めた**（Fail）
3. X が触る id と B が変えた id（施行時の版にあって、起草時の版に同じ本文の項が無いもの。B が字句を改めた項は本文の近さで対応づける）が交わらなければ**独立**（Pass、`applyUnit_comm` を引く）。交われば調整規定（Fail）
4. X が加える本文と置換先の中の絶対参照「第N条第M項」を、起草時の版の項の本文で施行時の版に探し、番号が違えば手当てを生成する（Fail、`suggested_fixes`）。他法令への参照も同じ

## 4. 可換性による対応

id の世界（[ADR-0013](adr/0013-identity-patches.md)）では、B の項の挿入は X の指す id を動かさない。番号ベースの改め文で起きる「別の項を指す」は、
X を起草時の版に束縛して id にした時点で消える。残るのは「同じ id を両方が改める」だけで、それは `IndependentUnits` の否定として機械的に出る。

- 独立 → `applyUnit_comm`。順序に依らないので、施行日が未確定でもよい。調整規定は要らない
- 独立でない → 順序ごとに結果が違う（`scenario::explore` で列挙）。施行順が確定しているなら後の方を先の方の本文に対して書き直す（X を再束縛して改め文を描き直す = `lawean-render`）。確定していなければ調整規定で両方の順序を書く

改め文を id で管理していれば、B が来たときに X を**再束縛して描き直す**だけで済む。番号で管理しているから「改正法の改正」や調整規定が要る。
