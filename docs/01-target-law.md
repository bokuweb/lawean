# 01. 最初の対象法律

状態: **仮決定（借地借家法）**。異論がなければ確定。

## 選定基準

v0.1 のスコープ（人物・日付・期間・金額・条件・義務・禁止・許可・例外・参照）に対して、

1. **小さい**: 本則 50〜100 条程度。附則・別表が極端に多くない
2. **期間・日付が多い**: 時間モデルの検証に使える
3. **みなす / 推定する / ただし書き / 特則** が揃っている: ADR-0002, 0004 の検証に使える
4. **内部参照が多い**: 「前項」「前条」「第○条の規定にかかわらず」など。参照解決の検証に使える
5. **改正履歴がある**: 直接改正とハネ改正の両方の実例が取れる（v0.2 以降の改正 patch 用）
6. 手続法でない: 状態遷移モデルは v0.1 の対象外
7. 実務でよく参照される: 検証結果の意味が分かりやすい

## 仮決定: 借地借家法

- e-Gov 法令 ID: `403AC0000000090`
- 対象バージョン: 現行（令和3年改正後）。過去版は v0.2 の改正 patch で扱う
- 民法第138〜143条（期間の計算）は Temporal モデルの前提として一緒に読む

### 想定される難所

- **附則の経過措置**: 施行前に設定された借地権には旧借地法が適用される（附則第4条〜）。「この法律の施行前」という時点条件と、
  廃止された旧法への参照を IR でどう持つか
- **定期借地権（第22〜24条）・定期建物賃貸借（第38条）**: 本則の複数条を一括で「かかわらず」で排除する特則。
  Exception が単一 Rule ではなく Rule 集合を指す
- **第9条・第16条・第21条・第30条・第37条（強行規定）**: 「この節の規定に反する特約で〜に不利なものは無効」。
  Rule ではなく「他の Rule 群に対するメタ制約」。v0.1 では `Unknown(intentional)` にするか、専用ノードにするかを 03 の例で決める
- **正当事由（第6条・第28条）**: 判断が開放的。Unknown（意図的に曖昧）の代表例
- **書面 / 電磁的記録**: 令和3年改正で追加。改正 patch の実例として後で使う
