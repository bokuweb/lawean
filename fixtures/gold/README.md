# 抽出の正解データ（gold）

`lawean-extract` の候補（`candidate::Candidate`）の適合率・再現率を測る正解。
jlsi/elsa の variable-extractor と同じ方針: **規則作成用と評価用を文書単位で分け**、
フィールド別に適合率・再現率を出し、抽出総数の増加を改善の根拠にしない。

## 形式（JSON Lines）

1 行 1 文。その文について**期待する候補をすべて**列挙する（空なら負例 = その文には候補が無い）。
gold に載っている文だけが対象で、その文に出た候補のうち gold に無いものは誤検出（FP）、
gold にあって出なかったものは見逃し（FN）。一致は (field, raw) の完全一致。

```json
{"sentence": "425AC0000000061/main/art:3/para:1/sent:1", "expected": [{"field": "elapsed", "raw": "前条第一項の政令の施行の日から起算して一年を経過する日"}]}
{"sentence": "425AC0000000061/main/art:2/para:1/sent:1", "expected": []}
```

## 文書の分け方

| 用途 | 法令 | 備考 |
|---|---|---|
| 規則作成（dev） | 借地借家法、公職選挙法、民法、高齢者居住安定確保法 | 規則はこれらを見て作った。被覆率（`examples/temporal.rs`）もこれらで |
| 評価（eval） | 大規模災害借地借家特別措置法（425AC0000000061）、借地借家法施行令（504CO0000000187）、同施行規則（504M60000010029） | **規則を作るときに見ない**。数字は `cargo run -p lawean-extract --example eval` |

eval の gold は候補の出力を見ながら人が判定して作った（出力を写したものではない。誤りは直した形で載せてある）。
規則を eval の文で直したら、その文は dev に移す。
